# autobuilder
AutobuilderN-Помощник по постройка из интернета по блокам и размерам для Бабфт(Build a boat). Является читом! 
Подробнее:я очень долго старался чтоб сделать этот чит, для многих новичков по Delta и другим эксплойтом им сложно настроить автобюлдер, но теперь с этим скриптом Новички смогут сделать много чего, лишь бы иметь все инструменты! 
Имейте видду, в Roblox недавно появился Античит в Babft, поэтому возможные ошибки при автобилде!
